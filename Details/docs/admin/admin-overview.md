# Admin Panel & Management Architecture

## 1. Executive Purpose
The Captains of Jawai Admin Suite is a custom, lightweight, enterprise-grade back-office application designed specifically for safari operators and luxury travel concierges. 

Unlike generic WordPress admin panels bloated with dozens of unmaintained plugins, this admin suite is built as a purpose-engineered PHP 8.3 / MariaDB application deployed directly into the GoDaddy cPanel environment.

## 2. Core Operational Modules
1. **Executive Operations Dashboard:** Real-time metrics on incoming inquiries, conversion velocity, pending follow-ups, and field calendar occupancy.
2. **Bespoke Inquiry CRM:** Comprehensive lead management tracking travellers from initial inquiry through consultative proposal to offline confirmation.
3. **Headless CMS Engine:** Direct visual management of safari experiences, destination guides, field journal articles, team bios, and customer testimonials without touching code.
4. **Media Asset Vault:** High-performance media library supporting image uploads, automatic WebP conversion, EXIF handling, and copyright rights tagging.
5. **SEO & Metadata Suite:** Granular control over meta titles, descriptions, canonical tags, and Open Graph previews.
6. **Security & Audit Logs:** Role-based access control (RBAC), CSRF protection, and audit logging of all sensitive administrative actions.
