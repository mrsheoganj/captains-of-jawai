# Headless Content Management Workflows

## 1. Publishing Workflow States
- `DRAFT`: Content saved privately, visible only in admin preview.
- `REVIEW`: Marked by editor for senior naturalist / manager approval.
- `PUBLISHED`: Live on production website; XML sitemap automatically updated.
- `ARCHIVED`: Unindexed from public search, preserved in database.

## 2. Markdown & Rich Editorial Authoring
- The journal and destination editors support rich Markdown editing with live side-by-side preview, clean formatting, image embeds, and pull quotes.
