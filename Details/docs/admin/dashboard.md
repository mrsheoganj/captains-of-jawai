# Executive Dashboard Specification & Metrics

## 1. Key Performance Indicators (KPI Cards)
- **New Inquiries (Last 7 Days):** Metric count with percentage comparison to previous period.
- **Active Journey Proposals:** Number of leads currently in `PROPOSAL_SENT` or `FOLLOW_UP` status.
- **Conversion Rate (Inquiry → Confirmed):** Monthly percentage calculation.
- **Average Response Time:** Time elapsed between inquiry submission and first staff contact.

## 2. Operational Feeds & Action Lists
- **High-Priority Leads Requiring Action:** Highlighted table of inquiries where `follow_up_date <= TODAY` or status is `NEW` for > 6 hours.
- **Upcoming Expeditions Calendar:** Visual timeline showing scheduled safari dates and guest parties for the next 14 days.
- **Inquiry Origin Map:** Breakdown of inquiries by traveler location (Domestic metros: Mumbai, Delhi, Ahmedabad, Bangalore vs. International: UK, USA, Europe).
