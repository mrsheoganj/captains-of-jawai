# Global Site Settings & Contact Configuration

Configurable via the admin dashboard without code edits:
- Business Legal Name & Trade Name.
- Primary Email, Notification Recipient Emails.
- Official WhatsApp Number & Pre-populated Message Strings.
- Direct Emergency Field Telephone Numbers.
- Office Registered Address & Geographic Coordinates.
- Social Profile Links (Instagram, YouTube, TripAdvisor).
- Maintenance Mode Toggle & Announcement Banners.
