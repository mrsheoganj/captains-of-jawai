# Role-Based Access Control (RBAC) Specification

| Role Name | Description | Permissions |
| :--- | :--- | :--- |
| **Super Admin** | Business owner / General Manager | Full unrestricted system access: user creation, database backups, settings, CRM, CMS, delete permissions. |
| **Expedition Manager** | Senior lead planner & naturalist coordinator | View/Edit all CRM leads, assign staff, publish journal posts, update safari details, view analytics. |
| **Sales / Concierge** | Frontline guest consultation staff | View assigned leads, update lead statuses, log internal notes, view safari availability calendar. |
| **Content Editor** | Copywriter / Digital marketing specialist | Create and edit Field Journal drafts, upload media, update FAQs and testimonials. No access to financial CRM data. |
| **Read Only** | External auditor / intern | View published content and reports without edit capabilities. |
