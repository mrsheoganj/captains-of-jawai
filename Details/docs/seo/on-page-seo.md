# On-Page SEO Standard Operating Procedure

## 1. Structural Tags & Semantic Markup
- **Exact H1 Rule:** Exactly ONE `<h1>` element per page, containing the primary target keyword naturally integrated into an evocative title.
- **H2 & H3 Subheading Discipline:** Subheadings must break content into logical thematic sections, incorporating semantic secondary keywords and question queries.
- **First 100 Words:** The primary target entity and regional context (e.g., *Jawai, Pali District, Rajasthan*) must appear within the first 100 words of body copy.
- **Image Optimization:** Every image must include descriptive, contextual `alt` text incorporating local geographic terms without keyword stuffing (e.g., `alt="Wild Indian leopard resting on sun-baked granite boulder in Bera, Jawai hills at dawn"`).

## 2. Meta Tag Architecture Standard
- **Title Tag Formula:** `Primary Keyword | Secondary Hook | Captains of Jawai` (Strictly under 60 characters).
- **Meta Description Formula:** Actionable, evocative summary under 155 characters ending with a clear invitation (e.g., *"Discover private 4x4 leopard tracking across the ancient granite hills of Jawai, Rajasthan. Expert local naturalists, ethical wildlife viewing, bespoke journeys."*).
- **Open Graph & Twitter Cards:** Comprehensive tags (`og:title`, `og:description`, `og:image`, `og:url`, `og:type="website"`, `twitter:card="summary_large_image"`).
