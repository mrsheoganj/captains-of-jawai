# Accessibility (a11y) & WCAG 2.2 AA Compliance

- Full keyboard navigability (Tab, Shift+Tab, Enter, Escape for modal close).
- Explicit visible `:focus-visible` outline rings styled in Burnished Amber (`#C8963E`).
- Screen reader announcements for dynamic multi-step form state transitions using `aria-live="polite"`.
- Semantic form field labels explicitly associated via `for` and `id` attributes.
