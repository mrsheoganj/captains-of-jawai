# Conversion Strategy & Funnel Architecture

## 1. Primary vs. Secondary Conversion Paths
```
[ VISITOR ENTRY POINT ]
         │
         ▼
[ PRIMARY PATH (High Intent) ]
  Action: Clicks "Plan Your Journey"
  Destination: Multi-Step Bespoke Inquiry Form
  Outcome: Rich lead created in Admin CRM with dates, party, preferences
         │
         ▼
[ SECONDARY PATH (Fast Contact) ]
  Action: Clicks "WhatsApp Consultation"
  Destination: Direct chat with pre-populated message
  Outcome: Instant WhatsApp lead logged into CRM
         │
         ▼
[ TERTIARY PATH (Editorial Engagement) ]
  Action: Explores Field Journal / Download Sample Itinerary
  Destination: In-article journey inquiry triggers
  Outcome: Contextual lead with tracked topic interest
```

## 2. Anti-Patterns Avoided
- No artificial scarcity timers ("Only 1 jeep left!").
- No fake discount countdown clocks.
- No instant credit-card checkout for unverified wildlife sightings.
